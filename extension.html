ImageSearch for Chrome.

Right-click any image on the web to crop it for social media or compress it. Add any page to your link page. Search photos without leaving what you’re reading.

Download for Chrome (.zip)

Free. Version 1.0.0. Works in Chrome, Edge, Brave and Opera.

Crop or compress any image

Right-click an image on any website and choose Crop for social media or Compress, resize or convert. It opens in the tool, ready to go. Nothing is uploaded.

Add pages to your link page

Right-click a page or a link and choose Add to my link page. Or use the toolbar button to add the page you’re on.

Search photos in one click

Select any text, right-click and search photos for it. The toolbar popup has a search box and quick links to every tool.

How to install it

  1. Download and unzip Unzip the file. You’ll get a folder called imagesearch-toolkit. Keep it somewhere permanent, because Chrome loads the extension from it.
  2. Open the extensions page Type this into the address bar and press Enter. Chrome doesn’t allow links to this page.
    chrome://extensions
  3. Turn on Developer mode It’s the switch in the top right corner.
  4. Click “Load unpacked” Choose the imagesearch-toolkit folder you unzipped. Select the folder itself, not a file inside it.
  5. Pin it (optional) Click the puzzle-piece icon in the toolbar and pin ImageSearch Toolkit so the search box is one click away.

Chrome may show a reminder about extensions in developer mode when it starts. That’s normal for extensions installed this way. To update later, download the new ZIP, replace the folder, then click the reload icon on the extension’s card.

What it can access, and why

  • Read and change data on all websites Chrome words it this way for any extension that can fetch an image from any site. It is used only when you right-click an image and choose a tool, to copy that one image, and to hand it to your ImageSearch tab.
  • Context menus Adds the right-click items.
  • Scripting Places the image into the tool page, as if you had chosen the file yourself.
  • Storage Remembers one setting: the address of your ImageSearch site.

The extension has no analytics and sends nothing to anyone. Your photos stay on your device: they go from the web page to a tab of this site, where the tools run in your browser. Its code is plain JavaScript in the folder you unzip, so you can read it before you install.
